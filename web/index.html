        Methodology — why these numbers hold up

        • Wilson score 95% intervals on every win rate — correct at 0%/100% and small samples, where naive normal-approximation error bars lie.
        • Work-limited, never time-limited: games run with a fixed hypothesis budget and no wall-clock deadline, so strength measures the algorithm, not the machine. Timings are reported separately and never affect results.
        • Seeded end-to-end: the same seed replays the same games bit-for-bit — any third party can reproduce a number exactly (sonar bench, verify-release).
        • E[shots] with standard error, not just means.
        • Handicap runs (opponent gets 2× time or 2× hypotheses) demonstrate the algorithm — not compute — carries the advantage.
        • Red-team verified: 2,420 hostile protocol inputs with zero panics; invariant stress across all variants (see EXPLOITABILITY.md).

        Full raw data and reproduction commands: BENCHMARKS.md in the repository. Live browser runs use the same engine compiled to wasm32 (simd128 backend).
