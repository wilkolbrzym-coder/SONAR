      Mods — write your own Sonar brain

      A mod is a JavaScript object with chooseMove(api) (required) and optional placeFleet, onObserve, onGameEnd. The api exposes 100% of Sonar's internal state — the full board view, the PDF density matrix and the Bayesian posterior. See Docs → Modding for the complete API. Illegal moves are auto-corrected and counted; three strikes forfeit a game.
